# KT Forge Company Homepage

A one-page homepage for KT Forge, my app studio, built with HTML and CSS Flexbox. This came out of the Flexbox section of Codecademy's Full-Stack Engineer path. The project lets you design a homepage for any company, so I used my own instead of making one up.

## What's on the page

A navbar with links to About, Products, and Team
A hero section with the studio's mission and a button down to the apps
Product cards for MyRouteBuddy, Habit Tracker: Pro, and AI Ebook Planner
A team section (it's just me, so it's four cards for the four hats I wear)
A footer with links to the website, GitHub, and LinkedIn

Flexbox handles all of the layout: the navbar, the row of product cards, and the team grid.

## Running it

No build step. Clone the repo and open `index.html` in your browser.
